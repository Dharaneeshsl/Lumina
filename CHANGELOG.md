# Changelog

All notable changes to Lumina are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

> **Note**: From v1.0.0 onwards, this changelog is automatically generated by our semantic-release pipeline. Entries below v1.0.0 were written manually.

## [Unreleased]

### Added
- Lumina AI Co-pilot v2 with multi-step reasoning chains
- Anomaly detection engine with configurable sensitivity thresholds
- Self-hosted Docker bundle for one-command deployment
- WebAuthn passkey support for passwordless authentication
- API key management UI with fine-grained scopes and rotation
- Funnel chart type for conversion analysis

### Changed
- Upgraded Prisma to 7.9.1 with improved pg adapter performance
- Improved error messages across all API endpoints
- Refactored notification system to use Novu as primary provider

### Fixed
- Fixed race condition in auth token refresh during concurrent requests
- Fixed memory leak in WebSocket connection manager
- Fixed incorrect timezone handling in scheduled report delivery

## [0.9.0] - 2026-07-15

### Added
- **Real-time WebSocket chart updates** — dashboards now refresh live without page reload
- **Row-Level Security (RLS)** — dynamic data filtering based on authenticated user context
- **Dashboard version history** — full diff view with one-click restore capability
- **Two-factor authentication (TOTP)** — TOTP authenticator app support (Authy, Google Authenticator)
- **Embed SDK v1** — embed any Lumina chart into third-party web applications
- **Slack notification integration** — deliver alerts to any Slack channel or DM
- **Organization teams & roles** — granular permissions: Owner, Admin, Editor, Viewer
- **CSV/Excel import** — drag-and-drop file ingestion with automatic schema detection
- **React Email templates** — beautiful, consistent transactional email designs
- **Prettier formatting pipeline** — auto-format on commit via Husky + lint-staged

### Changed
- **PostgreSQL connector v2** — 10x query performance improvement via connection pooling
- Upgraded TypeScript to 5.9 with strict mode enabled everywhere
- Upgraded Turborepo to 2.10 with improved remote caching
- Migrated from npm to Bun as the package manager

### Fixed
- Fixed dashboard sharing links expiring prematurely
- Fixed chart tooltips overflowing viewport on small screens
- Fixed OAuth redirect loop when user denies permission

### Security
- Patched XSS vulnerability in chart label rendering (thanks to @researcher via responsible disclosure)
- Added Content-Security-Policy headers to all web routes
- Upgraded better-auth to 1.6.25 with improved session management

## [0.8.0] - 2026-05-20

### Added
- **Google OAuth login** — sign in with Google Workspace accounts
- **GitHub OAuth login** — sign in with GitHub accounts
- **Resend email integration** — transactional email delivery with 99.9% deliverability
- **S3 storage integration** — file uploads backed by AWS S3 / Cloudflare R2
- **Redis caching layer** — session storage and query result caching
- **Pino structured logging** — JSON-formatted logs with OpenTelemetry support
- **Zod validation schemas** — runtime type safety at all API boundaries
- **better-auth integration** — replaced custom auth with better-auth library

### Changed
- Monorepo migrated from Yarn workspaces to Bun workspaces
- Turborepo pipeline configuration refactored for faster incremental builds
- Dashboard app migrated from Create React App to Vite 6

### Fixed
- Fixed login redirect loop in Safari due to SameSite cookie handling
- Fixed email verification link expiry not being enforced server-side
- Fixed avatar upload not accepting PNG files
